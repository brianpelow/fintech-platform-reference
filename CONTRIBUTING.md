# Contributing

Contributions should take the form of:

- New or updated ADRs (use docs/adr/000-template.md)
- Updated catalog definitions when services change
- Runbook improvements from operational experience
- SLO adjustments based on observed reliability data

## ADR process

1. Copy docs/adr/000-template.md to docs/adr/NNN-title.md
2. Fill in all sections
3. Open a PR for review by a Principal Engineer

## Standards

- All catalog definitions must be valid Backstage YAML
- SLO targets must be agreed with service owners
- Runbooks must be tested in staging before merging
